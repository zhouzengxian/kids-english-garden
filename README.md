# Kids English Garden 🌸

一个面向儿童的 3D 英语学习花园，通过交互式 3D 场景让孩子们在游戏中学习英语词汇。

## 功能特点

- 🎮 3D 交互式花园场景
- 📚 丰富的英语词汇学习
- 🎯 游戏化学习体验
- 🌸 美丽的花园装饰元素

## 文件说明

```
kids-english-garden/
├── index.html           # 主页面入口
├── garden-3d.js        # 3D 花园逻辑
├── styles.css           # 样式文件
├── three.min.js        # Three.js 3D 引擎
├── OrbitControls.js    # 3D 相机控件
└── vocabulary-data.json # 词汇数据
```

## 运行方式

### 本地运行

1. 直接用浏览器打开 `index.html`
2. 或使用本地服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 http://localhost:8000

直接访问: https://zhouzengxian.github.io/kids-english-garden
